# Roadmap

## Phase 1: Agency Lead OS Foundation

- Monorepo architecture
- App shell, landing page, onboarding
- RBAC, rate limits, audit logging
- Agency multi-client model
- Lead Magnet discovery and outreach queue
- Meta lead ingestion API
- WhatsApp command inbox
- AI qualification API
- Lead command center
- Copilot foundation
- Database schema

## Phase 2: Conversion Automation

- Queue-backed Meta and WhatsApp workers
- Approved-source discovery connectors
- Consent-policy and suppression-list enforcement
- WhatsApp Cloud API provider adapter
- Meta Lead Ads webhook verification
- Workflow persistence and versioning
- Conversation state machine
- Voice note transcription and summaries
- Booking calendar integrations
- Client report automation

## Phase 3: Scale Intelligence

- Realtime collaboration
- Row-level security policies
- SSO and SCIM
- Vector search over conversation and lead history
- Conversion likelihood model service
- Autonomous source expansion recommendations
- Conversation intelligence
- Agent evaluation harness
- Admin console for governance, retention, and data residency
